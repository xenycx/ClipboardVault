Python client

One file, no packages to install. Run it with no arguments, or double-click it on Windows, for a full-screen browser with search, paging, file pickers, and resumable uploads and downloads of any size. Python 3.8 or newer.

# full-screen interface: browse, search, pick files, download
python vault.py
# or use commands: upload files or a folder's contents
python vault.py up report.pdf photos/*.jpg
# list, search, and download
python vault.py ls invoice
python vault.py get 3f2a9c1e
# save text from a pipe, read it back
git diff | python vault.py paste --tag diff
python vault.py cat 3f2a9c1e
